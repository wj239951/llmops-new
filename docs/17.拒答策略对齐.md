# 拒答策略对齐（方案 A：只依据资料）

- 日期：2026-11-17
- 前置：docs/15 §3（检索说命中、模型说不知道）、docs/16 §5（检索拦住了，模型编了个"1000 公斤"）
- 结论：**命中时禁止模型用常识补充；无命中时直接回固定话术，不调用模型**

## 1. 改了什么

### 1.1 命中时的提示词

旧：

```
请基于以下知识库内容回答问题。
如果知识库内容不足，请说明不足，再结合通用知识补充。
```

新（`RAG_STRICT_GROUNDING=true`）：

```
请只依据下面的知识库片段回答问题，数字与结论必须来自片段原文。
片段里没有的信息，直接回答"知识库未收录该信息"，不要用常识补充，不要猜测或编造。
如果引用了片段，在回答末尾标注编号，例如【依据：知识片段1】。
```

### 1.2 无命中时

不再把原问题丢给模型（那等于邀请它自由发挥），直接返回固定话术：

> 知识库里没有检索到与这个问题相关的内容。可以补充设备型号、文件名称，或换个说法再问一次。

实现上把固定话术包装成与 LLM 流式同构的分片（`_canned_stream`），复用下游的 delta/done 处理，`meta`/`done` 的字段与正常回答完全一致，只是 `total_tokens=0`、`timings.llm_ms=0`、`sources=[]`。

### 1.3 开关与回滚

| 配置 | 默认 | 关掉的效果 |
| --- | --- | --- |
| `RAG_STRICT_GROUNDING` | true | 回到"结合通用知识补充"的旧提示词 |
| `RAG_NO_HIT_REPLY_ENABLED` | true | 回到"no_hit 也交给模型回答"的旧行为 |

两条路径都改了：非流式 `chat()` 与流式 `stream()`；后者是前端真正在用的那条。

## 2. 效果（同一套冒烟，端到端）

| 用例 | 改之前 | 改之后 |
| --- | --- | --- |
| 单轮：ZX-1200 锁模力 | 「1200 千牛」（无出处） | 「1200 千牛**【依据：知识片段1】**」 |
| **近域无答案：模具重量上限** | 19.3 s，模型编「通常为 **1,000 公斤**」 | **4.3 s，0 条引用，回固定话术** |
| 多轮第 1 轮：最大注射量 | 「260 克」 | 「260 克。【依据：知识片段1】」 |
| 多轮第 2 轮：那它的滤芯多久换一次 | 「每 400 小时」（无出处） | 「每 400 小时。【依据：知识片段2】**」——片段 2 正是 89 号手册，引用没标错 |

两个直接收益：

1. **幻觉数字消失**：no_hit 那条从"编 1000 公斤"变成"未检索到"，而且不用等模型，**4.3 s 返回**（原来是 19–21 s，一次生成全免）。
2. **答案可溯源**：命中时模型会标注 `【依据：知识片段N】`，与 `sources` 数组的下标对应得上（第 2 轮引用片段 2，正好是排第二的 89 号手册）。

## 3. 代价与风险

1. **能力看起来变弱**：以前问库外问题会得到一段"虽然没查到但可以这样理解"的通用回答，现在只有一句话。这是明确的产品取舍——对工业知识库，错误数字比"不知道"贵得多。
2. **"命中但片段不含答案"会走向另一个极端**：模型现在被要求说"未收录"，可能把本可以答的问题判成未收录。这需要端到端评测量化，目前只有单例观察。
3. **引用编号依赖模型自觉**：提示词给了要求，但没有强校验；模型偶尔可能标错编号或漏标。要硬保证得在生成后做引用校验（解析 `【依据：...】` 与 `sources` 对齐），本次没做。
4. **`weak_hit` 的处理没变**：仍是"照答，但前端可标弱依据"。严格来说它也该降级话术，取决于前端怎么展示。

## 4. 回归

`119 passed`（新增 `tests/test_grounding.py` 5 条）：

- 严格提示词包含"只依据 / 知识库未收录该信息"，且不含"结合通用知识补充"；
- 关掉开关后提示词回到旧模板；
- no_hit 流式返回固定话术、不调用模型、`llm_ms=0`；
- 命中时传给模型的 query 是收紧后的提示词，且带上片段正文。

另外把两个编码了旧行为的用例改成了显式契约：

- `test_chat_no_hit` → 断言固定话术 + 模型不被调用；
- `test_stream_event_order_and_meta` → 显式关掉固定话术，继续测"有模型流"时的事件顺序（这个用例的本意不是测拒答策略）。
